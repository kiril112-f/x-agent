# Plate assets for the occlusion layout (l5). The model makes the object only — the compositor does the layout.
# Rules: one object in frame, front-facing, no perspective, no tilt, even diffuse light, plain light grey
# background, no text / letters / numbers / logos / watermarks, square 1:1 with generous margins.
# After generating, crop tightly to the object (magick in.jpg -fuzz 4% -trim +repage out.png) and drop it
# into assets/plates/.

shadowless lighting, plain light grey background, no text, no letters, no numbers, no logos, no watermark,
zero perspective, straight-on, centered, square 1:1 with generous margins.
