## Ответ

Практический guide можно сохранить: отдельное устройство → стабильное соединение → проверка фактического IP → создание аккаунта → изучение американской ниши → первые публикации и проверка географии аудитории. Самые важные исправления: дать рабочие SOCKS5-настройки Happ, убрать общий порог «90%», объяснить прогрев как авторскую рабочую последовательность, а YouTube отделить от сетевого таргетинга: его channel location не определяет рекомендации. Пользователь прямо подтвердил примерно 1.7M — использовать ровно заявленный личный результат без дополнительных выдуманных деталей.

## Подробности

### Готовая последовательность Happ для статьи

1. В IPRoyal открыть заказ **ISP Proxies**, выбрать US location и **SOCKS5**. Скопировать server/host (или IP), SOCKS5 port, username и password из этого заказа.
2. В актуальном IPRoyal guide стандартные порты: **12324 для SOCKS5**, **12323 для HTTP/HTTPS**. Использовать порт из своего dashboard: он может быть изменён. Не переносить `1080` из гайда другого провайдера.
3. В Happ: **+ → Manual Input → SOCKS/Socks5**. Ввести **Server address**, **Port**, **Username/User**, **Password**; нажать **Done**. Общая последовательность официально описана Happ; названия полей дополнительно показаны в [NodeMaven's Happ walkthrough](https://docs.nodemaven.com/en/articles/12982103-happ-proxy-utility-android-and-ios), это документация другого провайдера, поэтому его host/port не копировать.
4. Выбрать сохранённый сервер и подключиться; при первом запуске подтвердить системный VPN configuration prompt. Проверить, что routing profile направляет нужные приложения через proxy: у Happ бывают direct exceptions. [Официальный routing builder](https://routing.happ.su/) документирует GlobalProxy и direct/proxy правила.
5. Открыть IP-check в браузере: увидеть ожидаемый US exit IP и провайдера; повторить после переподключения. Это проверка пути браузера, а не доказательство US distribution или всего трафика всех приложений.

Альтернатива ручному вводу: Happ документирует `socks://USER:PASSWORD@HOST:PORT#US`. Для статьи проще и надёжнее поля: не надо объяснять escaping специальных символов. Не обещать импорт необработанной `host:port:user:pass` или HTTP-строки.

Сохранить авторскую routine: день подготовки, несколько дней просмотра релевантного контента, постепенное оформление и первые публикации. Формулировка «this is the routine I use» точнее «skip this and you are doomed to 200 views». Лента — рабочая библиотека референсов; география фактических зрителей — проверка результата.
