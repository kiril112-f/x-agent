## Установка в этом или другом аккаунте

1. Собрать переносимый ZIP командой `node scripts/export-dots-pack.mjs` из X Agent. Архив содержит инструкции и контекст, не секреты. Получить путь из вывода.
2. Открыть настоящий Dot в текущем аккаунте ChatGPT, передать `START-HERE.txt` и архив. Если Dot работает с подключённым ПК, дать ему этот каталог через поддерживаемый Computers flow. Не извлекать сессионные токены приложения и не пытаться вызвать скрытый API.
3. Подключить именно нужные Google Docs/Notion и X-сессию. Chrome login не переносится в облачный браузер Dot. Доступ к ПК требуется разрешить отдельно; Codex Sync этого не доказывает.
4. Dot должен прочитать пакет, перечислить реальные доступы и сохранить три обязанности из `schedules.json`. Сверить в Scheduled названия, часовой пояс и следующий запуск; записать настоящие IDs в `installation-state.json`.
5. Сначала ручной пилот с `test` runId: input → Dot → output → сервер → существующий Notion → Telegram. Затем один запуск по расписанию без вмешательства, повтор того же runId и проверка отсутствия дублей.
6. Только после пилота сменить метку аналитического исполнителя на сервере, отключить три X-analysis расписания Spark и прежний сборщик feed. Не запускать двух writers одного output Doc. X Algorithm Audit остаётся на паузе. Чужие проекты не трогать.

Переход на другой ChatGPT-аккаунт не переносит OAuth, владение Dot, расписания и сессии. Архив ускоряет восстановление; непрерывную работу без повторного подключения он не гарантирует. Серверные сборщики, official monitor и уже сохранённые Notion-данные не зависят от аккаунта ChatGPT.

## Приёмка

Проверить 0–3 конкретные карточки вместо тегов, contentPlan, первоисточники и отсутствие выдуманного опыта. Проверить пустую/устаревшую ленту, неверный runId, истёкший deadline, недоступный Dot/Chrome, повторы output и Telegram callback. Не повторять неизвестный исход записи. Исторические GPT-6.1 Sol / Eleven v4 — только TEST, не новые срочные новости. Хранить IDs сообщений и Notion-страниц, observedAt и sentAt, а не только надпись Completed.
