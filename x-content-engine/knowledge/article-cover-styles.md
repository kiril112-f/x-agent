## Dan Koe direction

This name is Kirill's requested library label. Use the general visual language: an original engraved scene, a tiny human figure, a vast environment, tactile ink, and one clear tension. It is a visual reference, not an instruction to copy another author's prose, exact artwork, or title.

The boat, astronaut, and falling person are separate examples within this direction. Avoid endlessly repeating the same black hole. Derive a fresh scene from the article's mechanism: a narrow crossing, an opening through a wall, a branching path, an outsize machine, a figure discovering an unfamiliar environment. Use negative space intentionally and check the silhouette at feed size.

Usually no cover text, or one short phrase when it materially clarifies the topic. No generic glowing AI brain, random network lines, or invented progress chart.

Reference 04 is the luminous color variant. Reference 05 is a separate banknote/editorial direction; do not merge it into the monochrome group. Reference 08 was described by the user as a popular X example; no measured popularity claim is recorded.
