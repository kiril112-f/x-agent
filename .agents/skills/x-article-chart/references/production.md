# Производство

Один маршрут: спека JSON → `chart.html` → Chrome headless → PNG. Image-моделей здесь нет вообще — они не умеют ни точные числа, ни выровненные подписи, а график без точности бессмысленен.

---

## Запуск

```powershell
.\assets\render.ps1 -Spec .\my-chart.json `
                    -Out ..\..\..\x-content-engine\assets\charts\install-sources\sources.png
```

| Параметр | Значение |
|---|---|
| `-Spec` | Путь к JSON-спеке |
| `-Json` | Спека строкой вместо файла — для одноразовой сборки |
| `-Out` | Путь PNG. Папка создаётся сама |
| `-Scale` | Множитель. Умолчание 2, то есть `wide` даёт 3200×1800 |
| `-KeepHtml` | Оставить собранный HTML рядом с PNG для отладки |
| `-Open` | Открыть готовый PNG |

Рядом с PNG автоматически ложится JSON-спека под тем же именем. Хранить обязательно: график должен пересобираться через месяц, когда правится заголовок или приезжает свежая цифра.

---

## Валидация

`render.ps1` проверяет спеку до рендера и печатает `WARN` жёлтым. Пустой вывод — хороший знак.

| Предупреждение | Что делать |
|---|---|
| `нет source` | Найти первичный источник или снять цифру с графика |
| `концептуальная кривая с source` | Подписать `Illustrative`, иначе форму прочитают как измерение |
| `emphasis стоит у N серий` | Оставить один акцент |
| `серий N при четырёх фирменных цветах` | Задать `palette` или сократить серии |
| `столбцов N` | Резать до семи или уходить в `tall` |
| `title длиной N` | Резать заголовок |

Рендерер добавляет свои предупреждения в консоль браузера: обрезанный при переносе текст, ненайденная точка аннотации, цифры в концептуальном графике. Чтобы их увидеть, собрать с `-KeepHtml` и открыть HTML в браузере.

## Отладка вёрстки

```powershell
.\assets\render.ps1 -Spec .\my-chart.json -Out .\tmp\test.png -Scale 1 -KeepHtml
```

`Scale 1` рендерит быстрее и достаточен, чтобы проверить композицию. Рядом останется `test.build.html` — его можно открыть в браузере, править инструментами разработчика и переносить найденные значения обратно в спеку.

`assets/chart.html`, открытый напрямую без спеки, рисует демо-кривую: шаблон всегда можно покрутить руками, ничего не рендеря.

## Проверка на телефоне

Обязательный шаг, который заменяет догадки: открыть PNG и уменьшить до **600 px по ширине**. Столько картинка занимает в теле статьи. Если подпись деления или источник не читаются — правится спека, а не «и так сойдёт».

## Где что лежит

```
x-content-engine/assets/charts/<slug>/
  sources.png        финал @2x
  sources.json       спека, которой он собран
  timeline.png
  timeline.json
```

`<slug>` — тот же, что у обложки статьи в `assets/covers/<slug>/`. Так все визуалы одной статьи находятся вместе.

Примеры рабочих спек — `assets/examples/`. Начинать с ближайшего примера, а не с пустого файла: в них уже проставлены поле, размер и порядок слоёв.

## Ограничения текущего рендерера

Знать заранее, чтобы не тратить время:

- Автопереносится только заголовок и подзаголовок. Подписи категорий, серий и регионов — однострочные; длинную формулировку нужно сокращать.
- Подписи расходятся только по вертикали. Если разошлись некрасиво, серий слишком много.
- Нет второй оси Y, и это намеренно (`chart-types.md` §1).
- Шрифт берётся из `C:/Windows/Fonts/Inter-VariableFont_opszwght.ttf`. На другой машине путь придётся поправить в `chart.html`.
