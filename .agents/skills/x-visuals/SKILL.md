# X Visuals

Не добавляй изображение по привычке.

Сначала проверь, не профильная ли это задача:

- Цифра, доля, динамика, сравнение или утверждение о форме зависимости — `$x-article-chart`.
- Обложка, превью или header статьи — `$x-article-cover`.

Этот скилл остаётся для всего остального: скриншотов, product UI, before/after и редких branded-визуалов.

Приоритет:

1. Реальный screenshot, metric, product UI или before/after.
2. Простой document visual или diagram с одной идеей.
3. Сгенерированный branded visual, если первых двух нет и он добавляет смысл.

Правила:

- Один визуал — одна идея.
- Текст должен читаться на мобильном thumbnail.
- Не проси image model надёжно набрать важный текст. Генерируй фон/иллюстрацию, затем накладывай точный текст через HTML/CSS, SVG или canvas.
- Не скачивай и не переиспользуй чужое изображение без разрешения/допустимого источника. Для reference поста лучше embed/quote или собственная реконструкция данных с атрибуцией.
- Сохраняй спокойный consistent style; не превращай каждую публикацию в бренд-постер.

Локальный workflow описан в [references/zubbix-studio.md](references/zubbix-studio.md). Перед внешней публикацией всегда показывай итог пользователю.
