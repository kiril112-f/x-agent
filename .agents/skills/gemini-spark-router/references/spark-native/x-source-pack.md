# Spark skill: x-source-pack

**Статус 29.09.2026: вспомогательный первый этап по запросу.** Проверка тестового пакета 28.09: 19 из 20 цитат совпали с источниками дословно, вердиктов нет. Слабое место — выбор источников: Spark может взять устаревшую страницу. Перед использованием X Agent сверяет каждую цитату и дату с текущей официальной страницей; основной путь — `x-content-research`.

Эталон навыка, созданного в Gemini Spark (Навыки → Создать вручную) 28.09.2026. При изменении — сначала правка здесь, затем та же правка в Spark.

Почему этот этап отдан Spark: в пилоте 27.09 все 8 цитат Spark были настоящими, ошибались только его вердикты и выводы. Навык поэтому запрещает вердикты — он только находит первичные источники и дословные цитаты. Проверку утверждений, выводы и текст поста по-прежнему делает `x-content-research` и дальнейшие навыки X Agent.

## Название

x-source-pack

## Описание

Используй, когда для поста, треда или статьи в X (проект X Agent) нужно собрать источники по теме: найти первичные публичные источники и выписать из них точные цитаты без собственных выводов. Не используй для написания текста поста.

## Инструкции

Ниже — текст, фактически сохранённый в Spark. Spark отклоняет инструкции, в которых строки начинаются с «- » (ошибка INVALID_ARGUMENT при сохранении), поэтому списки записаны через «;» и нумерацию в скобках.

```text
Цель: подготовить для X Agent проверяемый «пакет источников». Выводы, проверку утверждений и текст поста делает X Agent после тебя — ты только находишь источники и дословные цитаты.

Вход: тема или тезис, 1–8 вопросов, иногда стартовые ссылки. Если вопросов нет — сформулируй 3 проверяемых вопроса и покажи их в начале.

Иерархия источников: (1) официальная документация, исходный код, анонсы компаний и продуктов, отчёты, собственные данные; (2) оригинальные интервью, выступления, датасеты, научные статьи, прямые посты автора; (3) надёжные СМИ со ссылками на доказательства — только чтобы найти первичный источник, помечай «вторичный»; (4) мнения практиков — только как контекст, помечай «мнение». Форумы, комьюнити-треды и пересказы без ссылок не используй как доказательство. Посты в X — только публичные, без входа в аккаунт; пост подтверждает лишь то, что автор это сказал.

Для каждого источника укажи: номер и тип (первичный, вторичный или мнение); название страницы, организацию или автора; дату публикации или обновления (если нет — «дата не указана»), отличая дату события от даты публикации; точный URL; 1–3 дословные цитаты в кавычках на языке оригинала, каждая не длиннее 25 слов, без сокращений и склеек; номера вопросов, к которым он относится.

Правила. Не пиши вердикты вроде «подтверждено» или «опровергнуто», не обобщай, не делай выводов и рекомендаций. Не пересказывай вместо цитаты; цифры, даты, цены и лимиты — только если они есть в цитате. Если по вопросу первичного источника нет — напиши «Вопрос N: первичный источник не найден» и что искал. Если страница не открылась — укажи это, не цитируй по памяти. Итого 5–12 источников без дублей.

Результат: создай приватный Google Документ «X source pack — тема — дата» с вопросами, таблицей источников и разделом «Не найдено / не открылось». В чате дай ссылку на документ и список вопросов без ответа. Не публикуй, не пиши в X, не отправляй сообщений, не создавай других файлов и расписаний.
```

## Как X Agent использует результат

`x-content-research` принимает пакет как готовый список кандидатов-источников: выборочно открывает цитаты, строит evidence ledger, выводы и вердикты сам. Пакет не записывается в Notion как есть.

## Откат

Spark → Навыки → x-source-pack → выключить. Обычный `x-content-research` работает без Spark.
