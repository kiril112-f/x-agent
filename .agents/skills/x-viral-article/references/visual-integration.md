# Визуалы в статье

Статья без визуалов не считается готовой. Во всех 19 разобранных статьях визуалы идут каждые 1–3 секции и работают как доказательство, а не как украшение.

Отсюда скилл вызывает три других: `$x-article-cover` (обложка), `$x-article-chart` (графики и инфографика), `$x-visuals` (скриншоты и кадрирование).

---

## Карта слотов

**Слот 0 — обложка. Обязательно.**
Вызов: `$x-article-cover`.
Вход: тема/обещание, выбранное направление, reference IDs, cover copy или `no_text`, реальные assets/proof, crop. До новой статьи предложить 2–3 стиля с сохранёнными картинками и спросить выбор, если он ещё не указан и исследование не делегировано.
Обложка показывает механизм, сюжет или подтверждённый результат. В art-led гравюре текст необязателен. Для текстовой обложки нужна большая выразительная типографика с осмысленным перекрытием и глубиной. Текст и настоящие знаки брендов — отдельные слои. После каждой существенной итерации сравнить свой PNG с оригиналом рядом и при 340 px.
Путь: `x-content-engine/assets/covers/<slug>/cover.png`.

**Слот 1 — блок результата сразу после первого экрана. Обязательно, если есть цифры.**
Форма `stat` из `$x-article-chart`, три числа.
Точно так работают adamtwtz ($21,418 → 23.1M views → $25k MRR) и lucaspatiri_ (2.6B views / 590 creators / 22,504 videos).

**Слоты 2..n — по одному на каждую секцию с числовым утверждением.**

| Что показываем | Форма | Скилл |
| --- | --- | --- |
| Сравнение вариантов, каналов, ставок | `bars` | `$x-article-chart` |
| До/после, старое/новое правило | `split` | `$x-article-chart` |
| Динамика с реальными точками | `line` | `$x-article-chart` |
| Форма явления без точных данных | `curve` + подпись `Illustrative` | `$x-article-chart` |
| Три главные цифры | `stat` | `$x-article-chart` |
| Кабинет, аналитика, интерфейс, чек | скриншот | `$x-visuals` |

Путь для графиков: `x-content-engine/assets/charts/<slug>/<name>.png`.

---

## Правило связки цифра ↔ график

На этапе проверки доказательств каждое число в статье получает одну из трёх пометок:

- **есть источник** → можно строить график, источник в подписи;
- **оценка** → только `curve` с подписью `Illustrative`, без осей с цифрами;
- **нет опоры** → число удаляется из текста.

Сверка по `x-content-engine/knowledge/proof-and-claims.md`. График никогда не придумывает данные, которых нет в теле статьи.

---

## Каденс

- 1 визуал на 300–500 слов. Для 1500 слов это 4–5 слотов плюс обложка.
- Никогда два визуала подряд без текста между ними.
- Один визуал — одно утверждение. Две идеи на одной картинке — разделить.
- Подпись под визуалом говорит, что из него следует, а не описывает его.
- Скриншоты с чужими личными данными — замазывать (`privacy-and-approval.md`).

---

## Обратная связка

`$x-article-cover` и `$x-article-chart` вызываются не после статьи, а из неё: скилл статьи передаёт им готовые входные данные и получает файлы обратно.

В ответе агента всегда идёт блок `Визуальный план` со строками вида:

```
Слот 0 | cover | «One pipeline. Zero editors.» | $x-article-cover
Слот 1 | stat  | $21,418 / 23.1M / $25k MRR     | $x-article-chart
Слот 2 | bars  | CPM: Meta $14 vs organic $0.60  | $x-article-chart
```

Если рендер невозможен в текущей среде, план выдаётся всё равно — с готовыми командами рендера и JSON-спеками графиков, чтобы Кирилл запустил их локально.
