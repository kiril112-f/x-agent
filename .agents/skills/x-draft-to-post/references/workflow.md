# Workflow and format selection

## Input types

- Raw draft: preserve the thesis and distinctive lines.
- Reference material (post, article, video, screenshot, document or idea): identify whether it supplies topic, facts, structure or style. It does not determine the output format. Add Kirill's contribution without copying distinctive wording or claiming another person's experience.
- News/case: research first and separate event facts from interpretation.
- Bullet dump: find one post-sized idea; do not cram every bullet into the output.
- Article idea: create a strong first-two-line preview, then use headings and whitespace only when they help navigation.

## Format selection

- Short post: one sharp observation or reaction that fits naturally under 280 characters.
- Medium post: one idea that needs setup, mechanism and takeaway.
- Quote-post: use when Kirill asks for this format or the task specifically calls for an embedded post; a reference URL alone is not that request.
- Thread: a sequence is necessary and each post earns its place.
- Article: continuous reasoning, a detailed case or a guide that benefits from depth.

## Draft passes

1. Intent lock — what does Kirill actually mean?
2. Context/resources — which people, tools, products and primary sources make the topic concrete?
3. Evidence — which details are known, sourced, uncertain or private?
4. Story spine — real cause-and-effect sequence, no invented drama.
5. Architecture — hook, development, payoff; CTA only if earned.
6. Attribution — keep source links separately for Kirill to embed manually; do not add the reference author's name/@handle or origin-of-idea prefaces. Follow `context-storytelling.md` for necessary case or direct-quote attribution.
7. Voice — direct, youthful, ambitious, easy American English.
8. EPS compression — every sentence must add claim, proof, mechanism, consequence, example/resource or actual judgment.
9. No-slop edit — remove repetition and filler without flattening spoken rhythm.
10. Mobile read — semantic paragraphs with exactly one blank line between beats; no wall of text or arbitrary hard-wrap.

Do not manufacture a tidy intro/body/conclusion when a two-line post is stronger.
